# 🛍️ ShopZone — E-Commerce Store

A full-featured, Vercel-ready e-commerce shopping site built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

## 🔥 Firebase Integration
Product data is currently empty. Firebase will be connected to populate products, categories, and manage orders.

## 🚀 Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **State:** React Context + localStorage (cart)
- **Deployment:** Vercel

## 📦 Features
- 🏠 Home page with hero, features strip, categories, and CTA
- 🛒 Shop page with search, filter by category, and sort
- 📄 Product detail page with features list and add-to-cart
- 🧺 Cart with quantity controls and order summary
- 💳 Multi-step checkout (Info → Shipping → Payment)
- 📱 Fully responsive design
- 🔁 Cart persisted via localStorage

## 🛠️ Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ☁️ Deploy to Vercel

```bash
npx vercel
```

Or connect this GitHub repo at [vercel.com](https://vercel.com) for automatic deployments.
